# 🚀 Инструкция по запуску проекта

## ⚠️ Текущая проблема

**Node.js не установлен** → `npm` не работает → сервер не запускается

---

## 📋 Пошаговая инструкция

### Шаг 1: Установите Node.js

**Самый простой способ:**

1. Откройте https://nodejs.org/
2. Скачайте **LTS версию** (зеленая кнопка)
3. Установите (двойной клик на `.pkg` файл)
4. Перезапустите VS Code

**Проверка:**
```bash
node --version
npm --version
```

---

### Шаг 2: Установите зависимости проекта

В терминале VS Code:

```bash
cd /Users/admin/spin-to-win-rewards-1
npm install
```

Это займет 1-2 минуты. Дождитесь завершения.

---

### Шаг 3: Запустите сервер

```bash
npm run dev
```

Вы должны увидеть:
```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:8080/
```

---

### Шаг 4: Откройте в браузере

Нажмите на ссылку `http://localhost:8080/` или откройте вручную.

---

## 🔄 Если что-то не работает

1. **Убедитесь, что Node.js установлен:**
   ```bash
   node --version
   ```

2. **Перезапустите терминал** после установки Node.js

3. **Очистите и переустановите:**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

4. **Проверьте порт:**
   - Сервер должен быть на `http://localhost:8080`
   - Если порт занят, измените в `vite.config.ts`
