# 🔧 Установка Node.js для проекта

## Проблема
`npm` и `node` не найдены в системе. Нужно установить Node.js.

---

## ✅ Решение: Установка Node.js

### Вариант 1: Через официальный сайт (Рекомендуется)

1. **Откройте браузер** и перейдите на:
   ```
   https://nodejs.org/
   ```

2. **Скачайте LTS версию** (Long Term Support - стабильная версия)
   - Нажмите кнопку "Download Node.js (LTS)"
   - Выберите версию для macOS (Apple Silicon или Intel)

3. **Установите**:
   - Откройте скачанный `.pkg` файл
   - Следуйте инструкциям установщика
   - Введите пароль администратора при запросе

4. **Проверьте установку**:
   Откройте новый терминал и выполните:
   ```bash
   node --version
   npm --version
   ```
   
   Должны показаться версии (например, `v20.x.x` и `10.x.x`)

5. **Перезапустите VS Code** (чтобы обновить PATH)

---

### Вариант 2: Через Homebrew (если установлен)

Если у вас установлен Homebrew:

```bash
# Установите Node.js
brew install node

# Проверьте
node --version
npm --version
```

---

### Вариант 3: Через nvm (Node Version Manager)

```bash
# Установите nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Перезапустите терминал или выполните:
source ~/.zshrc

# Установите Node.js
nvm install --lts
nvm use --lts

# Проверьте
node --version
npm --version
```

---

## После установки Node.js

### 1. Закройте и откройте терминал заново
(Чтобы обновить PATH)

### 2. Перейдите в папку проекта
```bash
cd /Users/admin/spin-to-win-rewards-1
```

### 3. Установите зависимости
```bash
npm install
```

### 4. Запустите сервер
```bash
npm run dev
```

### 5. Откройте в браузере
```
http://localhost:8080
```

---

## Альтернатива: Использовать Bun

Если хотите использовать Bun (быстрее, чем npm):

```bash
# Установите Bun
curl -fsSL https://bun.sh/install | bash

# Перезапустите терминал

# Установите зависимости
bun install

# Запустите сервер
bun run dev
```

---

## Проверка установки

После установки выполните в терминале:

```bash
node --version   # Должна быть версия (например, v20.11.0)
npm --version    # Должна быть версия (например, 10.2.4)
```

Если команды не работают:
- Закройте и откройте терминал заново
- Перезапустите VS Code
- Проверьте PATH: `echo $PATH`
