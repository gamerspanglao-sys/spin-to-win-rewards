# 🚀 Как запустить сервер

## Правильный адрес

**Сервер запускается на:** `http://localhost:8080`

(Не на 5173! Порт настроен в `vite.config.ts`)

---

## Пошаговая инструкция

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите dev сервер
```bash
npm run dev
```

### 3. Откройте в браузере
```
http://localhost:8080
```

---

## Если не запускается

### Проверьте Node.js
```bash
node --version
npm --version
```

Должны быть установлены. Если нет - установите с [nodejs.org](https://nodejs.org/)

### Очистите и переустановите
```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Проверьте порт
```bash
lsof -ti:8080
```

Если порт занят, убейте процесс или измените порт в `vite.config.ts`

---

## Ошибка "connection failed"

Если видите "connection failed" в браузере:

1. **Проверьте, что сервер запущен** - в терминале должно быть:
   ```
   VITE v5.x.x  ready in xxx ms
   ➜  Local:   http://localhost:8080/
   ```

2. **Проверьте адрес** - должен быть `http://localhost:8080` (не 5173!)

3. **Проверьте консоль браузера** (F12) на ошибки

4. **Попробуйте другой браузер** или режим инкогнито

5. **Проверьте файрвол** - может блокировать локальные соединения

---

## Альтернативные команды

Если `npm` не работает, попробуйте:

```bash
# С Bun
bun install
bun run dev

# Или с yarn
yarn install
yarn dev
```
